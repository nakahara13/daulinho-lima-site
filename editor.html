Da ideia
para o blog.

Este endereço fica fora dos menus do site. Use-o para preparar as publicações da escola.

  1. Preencha o post e confira a prévia.
  2. Baixe o HTML e coloque na pasta blog/ do projeto, ou publique direto no GitHub abaixo.
  3. Após o envio ao repositório conectado, a Vercel atualiza o site e a lista de posts.
Publicar diretamente no GitHub

Envie apenas o HTML do post para o repositório conectado à Vercel. O token é usado nesta sessão e enviado somente à API do GitHub; ele não entra no arquivo gerado.

Use um token com acesso a este repositório e a permissão Contents: Read and write. Criar token no GitHub ↗
